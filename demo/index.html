BSelect

سلکت سفارشی، بدون هیچ وابستگی

یک ماژول جاوااسکریپت تک‌فایلی؛ تمام CSS داخل خود JS تعریف شده است و برای کار کردن به jQuery، Bootstrap یا هیچ کتابخانه‌ی دیگری نیاز ندارد. همه‌ی کلاس‌ها با حرف B شروع می‌شوند تا با بقیه‌ی برنامه تداخل نداشته باشند.

  • بدون وابستگی
  • CSS داخل JS
  • جستجوی قابل خاموش/روشن
  • چک‌باکس در حالت چند انتخابی
  • دسته‌بندی و صفحه‌بندی
  • پشتیبانی RTL
  • قابل دسترس با کیبورد
دیدن نمونه‌ها مستندات API در پایین صفحه

چطور به صفحه اضافه می‌شود؟

<script src="bselect.js"></script>
<div id="city"></div>
<script>
  const select = new BSelect(document.getElementById('city'), {
    data: ['تهران', 'شیراز', 'تبریز'],
    searchable: true
  });
</script>

ماژول را می‌توان روی یک <select> واقعی هم اجرا کرد؛ در این حالت گزینه‌ها و ترتیبشان مستقیماً از خود سلکت خوانده می‌شود.

ساده‌ترین حالت: آرایه‌ای از رشته‌ها

گزینه‌ها از یک آرایه‌ی ساده تزریق می‌شوند. جستجو خاموش است و انتخاب، مقدار را برمی‌گرداند.

مقدار انتخابی: —
new BSelect(el, {
  data: ['تهران', 'شیراز', 'تبریز', 'مشهد'],
  placeholder: 'شهر را انتخاب کنید',
  onChange: ({ value }) => { /* ... */ }
});
۲

جستجو؛ قابل فعال و غیرفعال کردن در زمان اجرا

جستجو فارسی/عربی را نرمال می‌کند (ی/ي و ک/ك یکی می‌شوند) و نتیجه را هایلایت می‌کند. با دکمه‌ی زیر setSearchable() را امتحان کنید.

جستجو: فعال
مقدار انتخابی: —
const s = new BSelect(el, {
  data: cities,
  searchable: true,
  onChange: ({ value, item }) => console.log(value, item)
});

s.setSearchable(false); // خاموش کردن جستجو
s.setSearchable(true);  // روشن کردن دوباره
۳

ورود اطلاعات از یک <select> واقعی

همان HTML را می‌نویسید؛ ماژول گزینه‌ها و <optgroup>ها را می‌خواند. مقدار selected و فرم‌ها هم حفظ می‌شوند.

مقدار انتخابی: —
<select id="city">
  <optgroup label="استان تهران">
    <option value="tehran" selected>تهران</option>
    <option value="varamin">ورامین</option>
  </optgroup>
</select>

<script>
  new BSelect(document.getElementById('city'), {
    searchable: true
  });
</script>

تزریق با رشته‌ی HTML

می‌توانید همان HTML را به‌صورت رشته بدهید؛ هم <select>، هم <option> تکی و هم لیست <ul>/<li> پشتیبانی می‌شود.

مقدار انتخابی: —
new BSelect(el, {
  searchable: true,
  data: `
    <ul>
      <li data-value="k1">کلید یک</li>
      <li data-value="k2">کلید دو</li>
    </ul>`
});

با multiple: true هر گزینه یک چک‌باکس می‌گیرد، «انتخاب همه» اضافه می‌شود و با maxSelected می‌توان سقف انتخاب را محدود کرد.

onChange —
getSelectedItems() []

حداکثر ۴ مورد را می‌توانید انتخاب کنید.

const s = new BSelect(el, {
  data: skills,
  multiple: true,
  searchable: true,
  maxSelected: 4,
  onChange({ values, items }) {
    console.log(values);      // ['js', 'css']
    console.log(items);       // [{ value, label, ... }]
  }
});

s.getValues();          // آرایه‌ی مقادیر
s.getSelectedItems();   // آبجکت‌های کامل

دسته‌بندی + جمع‌شدن گروه‌ها + صفحه‌بندی

گروه‌ها از group در داده یا از <optgroup> ساخته می‌شوند. با کلیک روی تیتر گروه، جمع می‌شود و با دکمه‌ی «انتخاب گروه»، همه‌ی اعضای آن (مطابق فیلتر فعلی) انتخاب یا حذف می‌شوند.

تعداد انتخاب‌شده: 0
new BSelect(el, {
  data: cities,        // هر آیتم: { value, label, group }
  multiple: true,
  searchable: true,
  pagination: true,
  pageSize: 4,
  groupsCollapsed: false
});
۹

بارگذاری غیرهمزمان (asyncData)

اگر داده‌ها را از API می‌گیرید، asyncData(done, fail) را بدهید؛ اسپینر نمایش داده می‌شود و بعد از رسیدن داده، لیست پر می‌شود.

مقدار انتخابی: —
new BSelect(el, {
  searchable: true,
  asyncData(done, fail) {
    fetch('/api/cities')
      .then(r => r.json())
      .then(done)
      .catch(fail);
  }
});

گزارش رویدادها

همه‌ی نمونه‌ها رویدادهای خود را اینجا ثبت می‌کنند تا رفتار ماژول را ببینید.

    متدهای عمومی

    متدتوضیح
    getValue()مقدار انتخاب‌شده (در حالت چند انتخابی، آرایه)
    getValues()همیشه آرایه‌ای از مقادیر
    getSelectedItems()آبجکت کامل گزینه‌های انتخاب‌شده (value، label، group، data)
    setValues(vals) / select(v) / deselect(v)تغییر انتخاب‌ها از کد
    clear()حذف همه‌ی انتخاب‌ها
    setData(data)جایگزینی گزینه‌ها (با حفظ انتخاب)
    addOptions(items) / removeOption(v)افزودن/حذف گزینه
    setSearchable(bool) / setMultiple(bool)تغییر قابلیت‌ها در زمان اجرا
    open() / close() / toggle()کنترل باز بودن لیست
    enable() / disable() / setDisabled(bool)فعال/غیرفعال کردن
    on(event, fn) / off(event, fn)گوش دادن به رویدادها
    refresh() / destroy()رندر دوباره / حذف کامل و بازگرداندن HTML اولیه

    رویدادهای سفارشی: bselect:change، bselect:select، bselect:deselect، bselect:open، bselect:close، bselect:search، bselect:pagechange، bselect:maxselected، bselect:load، bselect:clear، bselect:toggle و bselect:error.
